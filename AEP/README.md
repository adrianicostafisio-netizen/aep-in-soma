# AEP - IN SOMA - Avaliacao Ergonomica do Trabalho

Ferramenta digital para conducao de Avaliacoes Ergonomicas do Trabalho (AET) conforme NR-17.
Funciona como Progressive Web App (PWA) - pode ser instalada no celular sem app store.

## Acesso Online

Link do app: https://SEU-USUARIO.github.io/aep-in-soma

## Como instalar no celular

### Android (Chrome)
1. Abra o link acima no Chrome
2. Toque no menu (tres pontos) > Adicionar a tela inicial
3. Confirme - o icone AEP aparecera na tela inicial

### iPhone / iPad (Safari)
1. Abra o link acima no Safari
2. Toque em Compartilhar > Adicionar a Tela de Inicio
3. Confirme - o icone AEP aparecera na tela inicial

## Caracteristicas

- Funciona 100% offline apos o primeiro acesso
- Dados criptografados localmente com PIN
- Exportacao: HTML/PDF, Excel (XLSX), CSV
- Matriz de Risco com Metodologia Orbenk
- Mapeamento automatico da Tabela 23 do e-Social
- Responsivo: funciona em celular, tablet e desktop
